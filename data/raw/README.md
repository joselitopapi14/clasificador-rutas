# Datos Crudos (Raw Data)

Debido al gran volumen del dataset original (aprox. 30 GB), las imágenes no se almacenan en este repositorio. 

**Origen de los datos:** El dataset fue obtenido de Kaggle: [Fruit and Vegetable Freshness Dataset](https://www.kaggle.com/datasets/ibneshihab/fruit-and-vegetable-freshness-dataset).

**Ubicación de trabajo:**
El archivo original `fruit-and-vegetable-freshness-dataset.zip` se encuentra alojado en el almacenamiento persistente del equipo en Google Drive bajo la ruta `/Proyecto_ML_Frescura/data/raw/`.
